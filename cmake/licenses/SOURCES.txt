EnTT:
Fixed official v4.0.0, commit 85c6bba014049b5de8fad49d25424df2f1f6a8c1.
Local vendor/entt/src preserves the official header tree without patches.
EnTT-LICENSE.txt is installed verbatim from vendor/entt/LICENSE (MIT).
https://github.com/skypjack/entt/tree/85c6bba014049b5de8fad49d25424df2f1f6a8c1

SDL3, stb, SDL3 hidapi, and SDL3 yuv2rgb notices are installed verbatim from
the selected repository vendor files. Hidapi BSD is the included permissive
alternative; the upstream multi-license index is preserved as context.
SDL3's bundled libm (Sun Microsystems), qsort (Gareth McCaughan), rotate
(Andreas Schiffler / SDL_gfx), internal stb_image, miniz (Rich Geldreich),
and strtokr (CC0) also preserve notices in the actual local source files.
Those complete files are conservatively installed as license-source .txt
records, independently of which objects the final static link selects.
The retained SDL3 OpenGL bridge preserves Brian Paul / VMware notices in
SDL_opengl.h and Khronos notices in SDL_opengl_glext.h. The platform Vulkan
bridge preserves local Apache-2.0 notices in vk_platform.h and vulkan_win32.h;
these do not claim that a production Vulkan renderer has been implemented.
FastNoiseLite, KHR, and robin-hood-hashing notices are embedded in the actual local headers; those
complete headers are installed as license-source records, not development SDKs.
Local vendor/robin_hood.h identifies version 3.11.5 and preserves Martin Ankerl's
2018-2021 copyright and complete MIT license text in the installed header.

yaml-cpp:

license. Its exact upstream revision is unresolved. yaml-cpp-LICENSE.txt preserves
the official project's current MIT license, not an invented vendored version:
https://github.com/jbeder/yaml-cpp/blob/master/LICENSE

This unresolved vendor-origin detail remains explicit for later release review.

MSVC runtime files are toolchain components, not these third-party libraries.
