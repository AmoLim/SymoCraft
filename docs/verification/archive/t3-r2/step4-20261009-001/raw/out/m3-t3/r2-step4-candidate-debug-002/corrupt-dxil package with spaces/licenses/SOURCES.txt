Third-party license source records (checked 2026-10-09)

SDL3, stb, SDL3 hidapi, and SDL3 yuv2rgb notices are installed verbatim from
the selected repository vendor files. Hidapi BSD is the included permissive
alternative; the upstream multi-license index is preserved as context.
FastNoiseLite, KHR, and robin-hood-hashing notices are embedded in the actual local headers; those
complete headers are installed as license-source records, not development SDKs.
Local vendor/robin_hood.h identifies version 3.11.5 and preserves Martin Ankerl's
2018-2021 copyright and complete MIT license text in the installed header.

https://github.com/g-truc/glm/blob/0.9.9.8/copying.txt
https://raw.githubusercontent.com/g-truc/glm/0.9.9.8/copying.txt

GLAD:
Local vendor/glad/glad.h identifies generator glad 0.1.35.
glad-LICENSE.txt preserves the official v0.1.35 license text:
https://github.com/Dav1dde/glad/blob/v0.1.35/LICENSE
https://raw.githubusercontent.com/Dav1dde/glad/v0.1.35/LICENSE
This generator identity does not prove an exact upstream source commit.
Apache-2.0-LICENSE.txt preserves the complete Apache 2.0 text cited by that
GLAD license's Khronos specification notice:
https://www.apache.org/licenses/LICENSE-2.0.txt

yaml-cpp:
The stripped local vendor tree contains no release/version marker or standalone
license. Its exact upstream revision is unresolved. yaml-cpp-LICENSE.txt preserves
the official project's current MIT license, not an invented vendored version:
https://github.com/jbeder/yaml-cpp/blob/master/LICENSE
https://raw.githubusercontent.com/jbeder/yaml-cpp/master/LICENSE
This unresolved vendor-origin detail remains explicit for later release review.

MSVC runtime files are toolchain components, not these third-party libraries.
Debug_NonRedist and debug UCRT are local developer diagnostic components; their
presence in a Debug candidate does not authorize external redistribution.
