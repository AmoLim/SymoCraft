# 共享验证场景

本页定义可复现输入与观察条件，不维护用例通过状态。来源为当前 [TestScene](../../game/modules/world/src/test_scene.cpp)、[工作负载](../../game/modules/world/include/symocraft/world/benchmark_workload.h)、[参数解析](../../game/app/src/startup_options.cpp) 和 [主循环](../../game/app/src/application.cpp)。结果与必要失败样本只由 [VERIFICATION](VERIFICATION.md) 索引。

## 固定世界与启动入口

regression 场景版本 1，默认 seed 424242；生成版本、构建、配置、资源和世界摘要必须同时记录。世界为 441 个已创建区块、内圈最多 361 个参与绘制，不是无限地图。相同输入重建初始方块，不恢复玩家编辑，不保证真实操作轨迹或像素位级一致。

从仓库根目录使用本次实际构建的游戏，例如：

```powershell
./out/build/windows-debug/bin/SymoCraft.exe --scene regression --checkpoint four-chunk
./out/build/windows-debug/bin/SymoCraft.exe --world-summary --seed 424242 --scene regression --checkpoint four-chunk --test-edits
./out/build/windows-debug/bin/SymoCraft.exe --scene regression --checkpoint four-chunk --test-edits --smoke-frames 120
```

这些是输入示例，不表示该路径存在、已经构建或场景已通过。切换检查点通过重新启动，没有运行中传送；重启丢弃编辑。`--checkpoint`/`--test-edits` 仅适用 regression，world-summary 不渲染帧且不能与 smoke-frames 同用。资源预检接受独立的 renderer 选择，不与场景或采样混用。

平台 x/z 为 -24..24，先清空 y=158..174，在 y=160 放草方块，地板顶面为 161。墙角用圆石，低顶用橡木木板，边界目标为石头。这是自然世界上的人工测试覆盖，不缩小世界规模。

## 检查点与编辑

坐标为玩家身体中心，眼睛沿用其上方 0.65 偏移；yaw/pitch 单位为度，初始 FOV 45。

| checkpoint | 身体中心 x,y,z | yaw / pitch | 观察目标 |
| --- | --- | --- | --- |
| spawn | -20.5,161.9,-6.5 | 0 / -10 | 朝 +x 的平直路线 |
| positive-x | 14.5,161.9,2.5 | -63.435 / -25.16 | x=16 两侧目标 |
| negative-x | -17.5,161.9,2.5 | -63.435 / -25.16 | x=-16 两侧目标 |
| four-chunk | -2.5,161.9,-2.5 | 45 / -20.4 | x=0,z=0 四区块交点 |
| wall-corner | 6.5,161.9,6.5 | 45 / 0 | x=8、z=8 的三格高 L 墙 |
| low-ceiling | -6.5,161.9,6.5 | 0 / 0 | x=-8..-4,z=4..8,y=163 低顶 |
| single-block | 20.5,168,20.5 | -90 / -60 | 落向 (20,164,20)，预期稳定中心约 y=165.9 |

生成测试检查初始 AABB 不重叠，不证明落地、撞顶或墙角滑动正确；这些仍需真实物理观察。TestScene 安装前检查至少半径 3 的覆盖，span 引用模块静态只读数组。编辑通过真实世界入口，失败不承诺回滚已完成操作。

固定 16 次写入按八个位置依次执行“石头 5 -> 空气 1 -> 指定材料”：

```text
(15,161,0)   -> 橡木木板 8    (16,161,0)   -> 圆石 11
(-17,161,0)  -> 橡木木板 8    (-16,161,0)  -> 圆石 11
(-1,161,-1)  -> 橡木木板 8    (-1,161,0)   -> 圆石 11
(0,161,-1)   -> 橡木木板 8    (0,161,0)    -> 圆石 11
```

`--test-edits` 在首批网格前核对每步原 ID 并执行有序写入，不经过射线、输入、防抖或逐帧编辑，也不测编辑延迟。重复调用或初始状态不符拒绝，不能作为方块交互通过证据。人工复查不带此参数，使用相应检查点，按 Q/E 选择材料、拆放目标，间隔至少 0.25 秒，观察选择框、暴露面和碰撞。

## 三种 Benchmark 工作负载

benchmark 自动占用 regression 场景及检查点，要求新 output；不能组合手动 scene/checkpoint/test-edits/world-summary/smoke-frames/check-assets。warmup 为 0..600 秒，sample 为 1..600 秒；正式固定计划见 [方法](methods.md)。

- static：four-chunk 固定视点，不主动移动或编辑；检查正式段没有非预期持续网格重建。
- walk：spawn 起点，在 x=-20.5 与 20.5 之间往返，yaw 为 0/180，普通步行、不奔跑不跳跃；检查位置推进与转向，不能推定逐物理步相同。
- edit：four-chunk，按总经过时间每 0.25 秒到期一次；先执行 16 次正向写入，再反序撤销，循环恢复。长帧可能集中补齐到期编辑，保留 edit_lateness 与慢帧，不跳过操作改善成绩。

人工路线 `walk-positive-x-v1` 为 z=-6.5、yaw=0、pitch=-10 的单向路点 x=-20.5/-16.5/-0.5/15.5/20.5。41 单位、步速 4.4，约 9.3 秒仅供人工定位，不是自动 benchmark 往返或输入回放。

## 玩法与恢复观察

以下保留共享玩法检查意图，不搬入历史逐项状态或批准。后端、版本和硬件范围由本次任务约定确定，GL 的通过不替代 D3D12/Vulkan。

| 原稳定身份 | 必要操作与观察 |
| --- | --- |
| M2-01 启动/资源 | 从交付与另一约定工作目录启动，检查真实地形纹理、日志与资源定位；保启动目录及画面 |
| M2-02 出生/落地 | 无输入落地后静止 20 秒，检查嵌入、穿地、漂移与无限下落；保全过程观察 |
| M2-03 移动 | W/S/A/D、松键、斜走及左 Shift；方向正确、松键停水平移动、斜向不额外加速，比较位移/时间 |
| M2-04 跳跃 | 平地起跳、空中再次按、落地再跳、走下台阶后尝试跳；保连续动作，不能获得意外空中跳跃 |
| M2-05 碰撞 | 正面/斜面墙、墙角、低顶与单方块落地，观察穿透和持续弹开 |
| M2-06 视角/窗口 | 转向、俯仰、滚轮、尺寸改变；比例/视口正确，俯仰/FOV受限，无不可恢复黑屏 |
| M2-07 射线/选择 | 不同面、距离、遮挡、快速转向点击；选择对应当前目标，超过约3单位不编辑、不选背后遮挡物 |
| M2-08 选材/编辑 | Q/E完整八种类型循环、左右键拆放、持续按及双键；约0.2秒冷却、不损坏世界，保每类操作和结果 |
| M2-09 区块交界 | 正负16边界、四块交点拆放；无错块/持久裂缝，两侧暴露面更新，记录位置与操作顺序 |
| M2-10 高度/外围 | 最底/最高层及有限世界外围；边界不崩溃/破坏内存，回退策略明确，不要求无限世界 |
| M2-11 无碰撞调试 | Caps Lock按住/释放与Ctrl下降，正常重力/碰撞恢复；不以键盘灯判断模式，不要求新增上升飞行 |
| M2-12 长帧/焦点 | 拖窗、切出切回、最小化约10秒后恢复；静止和移动分别检查时序，无无限追赶/持续失控 |
| M2-13 退出/重启 | Esc、关闭按钮分别退出并重新启动；保退出日志、状态及重启画面，不从进程结束猜退出原因 |
| M2-14 启动失败 | 隔离副本缺/坏资源或不支持能力；清楚报错/非零退出、不继续无效循环、不改原资产 |

15 分钟连续玩法从进入可操作世界后计时：0-3 分钟移动跳跃，3-7 分钟编辑，7-10 分钟边界，10-12 分钟窗口恢复，12-15 分钟回到旧场景继续操作与静止。不中途重启绕过异常，记录内存/帧时与未解释错误；短程通过不证明无泄漏。

原 ST-60 为连续60分钟循环，每5分钟观察可比场景资源使用与错误；ST-RESTART 为多次独立启动/进入/操作/退出，记录次数/退出状态。两者独立，不由15分钟推定。有限帧、CPU夹具和截图也不能替代人工连续体验。无法安全执行的边界具名标未执行，必要时补底层测试，不制造通过状态。
