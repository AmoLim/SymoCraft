### 生命周期与调用顺序

```text
待填：负责人取得依赖 → 初始化入口 → 正常调用 → 结束借用 → 清理入口 → 销毁依赖
失败：触发条件 → 部分状态与清理负责人 → 允许再次使用 / 退出
```

- 状态负责人：单实例 / 多实例、是否进程内共享、重置与重建的实际支持范围。
- 依赖与借用：参数和返回值的持有者、失效时机；不得跨越 view/handle 的有效边界。
- 线程 / callback / 重入：当前执行线程、禁止调用及清理前的结束责任。
- 分配与外部副作用：仅记录实际机制；资源对象的详细契约链接其笔记。
