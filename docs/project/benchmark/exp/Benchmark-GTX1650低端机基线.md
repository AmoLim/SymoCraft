## 核心结果

FPS / P95 / P99 为逐轮指标的三轮中位数；最大帧取三轮最大值。完整逐轮摘要保留在证据目录。

| 场景 | FPS | P95 ms | P99 ms | 最大帧 ms |
| --- | ---: | ---: | ---: | ---: |
| static | 60.64 | 20.8622 | 24.4782 | 41.1302 |
| walk | 60.64 | 21.5394 | 24.7828 | 47.1006 |
| edit | 69.75 | 17.4782 | 21.5254 | 439.8147 |

九轮退出码均为 0，无重试、取消、超时或强制结束，正式 101,672 帧，GPU 查询缺失 9 帧。失焦估计 1,618.319 秒（99.90%），不是遮挡面积。未收到独立快速检查记录，不补写通过。

8/9 轮 P95 高于中端 16.7 ms 参考线，9/9 轮 P99 低于 33.3 ms；原离线分析记录 35,788 帧超过 16.7 ms、10 帧超过 33.3 ms、2 帧超过 100 ms。低端硬阈值仍待确认，不以中端参考线或本次观测倒定低端通过线。

- edit 三轮 FPS 为 59.68 / 69.75 / 71.98，最大/最小差约 20.62%，edit 2 后半程持续变快。缺少后台/频率/调度同步证据，根因未定，不只选快轮。
- static / walk 无编辑或重建，仍每帧整理上传约 55.09 MiB。pack 均值的三轮中位数约 8.53 / 8.57 ms，upload 约 7.84 / 7.82 ms，GPU draw 约 0.67 / 0.56 ms。优先调查重复整理、上传及驱动等待，不把 CPU 墙钟当纯计算；pack 已含于 submit 不含 upload，GPU draw 不含上传、clear、swap。
