## 核心结果

以下 FPS / P95 / P99 为各场景逐轮指标的中位数；最大帧取该场景三轮最大值。逐轮数据见 [analysis.json](../evidence/laptop-y9000p-20261005/analysis.json)。

| 场景 | FPS | P95 ms | P99 ms | 最大帧 ms |
| --- | ---: | ---: | ---: | ---: |
| static | 91.55 | 11.9523 | 13.1760 | 22.2485 |
| walk | 92.31 | 12.0070 | 13.2957 | 24.9828 |
| edit | 90.86 | 12.7132 | 14.0737 | 91.2760 |

正式 147,782 帧，GPU 查询缺失 9 帧；336 帧超过 16.7 ms、1 帧超过 33.3 ms，无超过 100 ms 的帧。九轮均满足现有 P95 ≤16.7 ms / P99 ≤33.3 ms 数值条件，但不是零卡顿或 M2/M4 整体验收。

- 正式失焦估计 1,505.798 秒（92.95%），含预热 5 次转换。九轮首帧失焦；static 1 在 0.5294799 秒首次获焦并有后续切换，其余八轮未获焦。失焦只记条件，不删帧或追加前台重测门槛。
- edit 2 / frame 7112，elapsed 86.2611256 秒（含预热）：帧时 91.276 ms，present CPU 77.3482 ms；同帧 1 次编辑、3 次重建，mesh 2.4173 ms、upload 5.3068 ms、GPU draw 0.212992 ms。异常主要位于呈现 CPU 墙钟区间，不能确定是编辑或系统调度所致。
- edit 各轮 720 次写入、2,160 次重建；编辑帧 P95 为 14.4104 / 16.4027 / 13.6268 ms。walk 有往返，static/edit 固定位置。
- static / walk / edit 的 pack 均值中位数为 5.5288 / 5.5514 / 5.5048 ms，upload 为 4.7252 / 4.8695 / 4.8141 ms；无编辑时仍每帧上传约 55.09 MiB。pack 已含于 submit 不含 upload，GPU draw 不含上传、clear、swap，不重复相加或据此认定精确瓶颈。
- 含预热低频采样的工作集 / private bytes 峰值为 566.73 / 1,190.31 MiB，不证明无泄漏。main 至首次交换返回中位数为 1,690.49 / 1,621.96 / 1,651.83 ms，不是用户可操作时间。
