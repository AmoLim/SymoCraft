## 比较与证据边界

- 按同机、同场景、同画面和相同焦点策略比较；版本可变，但每版独立记录身份。保留供电、显卡模式、驱动、焦点比例和后台活动，不能仅凭 FPS 或单次会话推断代码优化。
- 基准成立不等于性能目标通过。低端硬阈值仍待确认；本批补齐 M2-T3 桌面/中端采样证据，不自动通过人工玩法、长期稳定性、M2/M4、其他后端或厂商验收。
- 温度、实际频率、后台活动和缺失 GPU 样本不反填估算值或零。每帧约 55 MiB 的整理/上传是调查入口，CPU 墙钟与 GPU draw 不能直接相加或当利用率。
- laptop / this 各 82/82 导出清单文件哈希通过，18 轮 CSV 复算与摘要一致；this 的 run/export 是同一会话，只计九轮。完整副本位于 `out/benchmarks/archive/<会话身份>`，docs 各保留 57 个精选原文件及分析/索引，不含完整 CSV 或 ZIP；本地副本不等于异地备份。
- 各机报告链接原始 session、分析与归档索引。后续按 [使用与交付](../使用与交付.md) 新建结果目录，不覆盖原始记录；本次不自动启动任何采样。
