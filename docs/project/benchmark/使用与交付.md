# Benchmark 使用与交付

关联功能：[[Benchmark-执行与导出]]、[[Benchmark-文件协议]]。

## 当前设计

这是 Windows x64 原生采样工具，不需要 PowerShell、Python、CLion 或管理员权限。游戏与执行器是两个进程；程序不会上传结果或修改电源、显卡、驱动设置。

### 运行条件

- Windows 10 1903 或更新版本 / Windows 11，x64。
- NVIDIA、AMD、Intel 均可尝试，必须安装支持 **OpenGL 4.6** 的实际显卡驱动。不能把厂商品牌当作版本能力保证。
- 1920×1080 固定帧缓冲、VSync 关闭。显示器/DPI 条件导致实际帧缓冲不匹配时，本轮失败，不偷偷降低分辨率。
- 采样使用普通无边框窗口，不是独占全屏，也不置顶；默认允许失焦时不抢焦点。保留 Windows 任务栏原有行为，任务栏可能遮住画面底部，不会因此降低渲染尺寸；不会修改任务栏自动隐藏设置。
- 游戏程序、assets 及随包 VC++ Release 运行库必须保留在同一解压目录结构中。不要在压缩软件内直接打开 exe。
- 导出 ZIP 使用 Windows 自带的 `System32/tar.exe`，不调用 shell。精简系统缺少 tar 时保留导出文件夹，报告失败；不会下载替代程序。

### 双击操作

1. 完整解压测试包，打开 `SymoCraftBenchmark.exe`，不要直接运行游戏代替执行器。
2. 机器代号填不含姓名的自定义代号。电源、显卡模式和频率设置不清楚时保留“未记录”；这些不是自动检测结论。
3. 先选“快速检查”：static / walk / edit 各 10 秒预热、10 秒采样，总采样协议 60 秒，另外有启动、验证、截图和落盘耗时。
4. 快速检查通过后选“正式基线”：三个场景各重复三次，每轮预热 60 秒、采样 180 秒，共 36 分钟，启动/导出耗时另计。
5. 默认允许切换到其他窗口，游戏不会在下一轮抢回焦点。**不要最小化游戏**、锁屏、休眠、远程切换图形会话或改显示配置。可最小化的是执行器窗口，不是游戏窗口。
6. 取消会停止本轮并保留诊断。失败后“重试失败轮次”从该轮新建 attempt 重新预热，再执行剩余轮次，不覆盖原始失败数据。重试组合不会标成连续正式基线。
7. 结束后使用“打开结果”检查，或“导出 ZIP”打包。只发送导出的 `results.zip`，不必回传游戏、DLL 或安装包。

### 如何理解结果

指定性能基准按 [项目范围](../../spec/project-scope.md) 分档：i7-10750H / GTX 1650 为低端，Y9000P / RTX 3070 Ti Laptop 为中端，开发台式机另作回归对照。中端沿用原 60 FPS / P95 / P99 目标；低端硬性目标待单独确认，不默认降低画质或将中端阈值移用为低端验收条件。[低端机九轮归档](exp/Benchmark-GTX1650低端机基线.md) 已有有效数据，但不代表受控前台或性能达标。

三份当前结果已按 [基准冻结 20261005](exp/Benchmark-基准冻结-20261005.md) 确定。用户说明每轮新窗口会失焦，本批 laptop / this 九轮均从失焦开始；沿用 allow-unfocused，失焦只记录到分析，不失败、不删帧，也不要求补跑纯前台才成立。最小化、尺寸改变、崩溃和数据不完整等仍分别检查。本次不改变软件内 strict 或普通游戏的行为。

`session.yaml` 是整组索引；每轮 `result.yaml` 是执行器判定；`capture/summary.yaml` 是游戏观测摘要；`frames.csv` 保留逐帧数据。`stdout.log`、`stderr.log` 保留诊断。表格 FPS 是吞吐量，不是显示器实际呈现帧率。

失焦只在 `allow-unfocused` 策略下允许。后台浏览器、视频、其他游戏等仍会竞争资源；驱动后台限帧也会影响结果。可运行不等于安静环境下的标准性能。对比时必须检查策略、负载版本、游戏/资源哈希和环境是否一致。

Alt+Tab 切到其他应用与手动最小化不同；普通窗口可以保持非最小化并继续采样，但被其他窗口遮挡时的默认 framebuffer/呈现行为依赖系统与驱动，不能承诺与完全可见的前台负载等价。窗口模式改动后的包有新游戏哈希，应重新建立同条件对照，不覆盖旧基线。

报告记录游戏实际使用的 `gl_vendor` / `gl_renderer` / `gl_version`。集成/混合显卡机器尤其需要复核，不以手填“独显直连”覆盖实际记录。CPU/GPU 温度当前原生执行器没有采集，标为缺失；NVX 显存只在支持扩展的设备上可用，不是跨厂商的进程显存指标。

### 保存和隐私

GUI 默认结果放在 `%LOCALAPPDATA%/SymoCraftBenchmark/results` 下的新目录，可改为其他可写目录。每次运行独立保存，不自动删除历史结果。

导出只包含固定白名单的采样文件，不包含 exe、DLL、用户名、主机名或硬件序列号的主动采集。导出文本替换已知的游戏目录、结果目录和用户主目录，原始本地日志不改。手填机器代号和第三方错误消息仍可能含个人信息，分享前检查；本工具不承诺通用匿名化。额外 PNG 是游戏帧缓冲，不是桌面截图。

## 本次变更

原生执行器候选版替代朋友侧 `.ps1` 操作。旧脚本及旧基线作为历史证据保留，旧版 v1 结果不能改写成 v2 有效结果。实现、实测与尚未完成项见 [[Benchmark-执行与导出]] 的验收章节。

当前包用于工程测试：低端 GTX 1650、中端 Y9000P 和开发机均已有冻结的 36 分钟基准；AMD/Intel Windows 真驱动、无开发环境电脑、人工玩法和公开发行许可材料仍须各自验收，不能由已有记录推定全部通过。原有第三方缺失许可材料见随包 `THIRD-PARTY-INVENTORY.md`，正式公开发行前需补齐。
