# Symocraft M2-A 桌面验收候选版

这是 Windows x64 / Release 开发验收包，不是最终公开发布版本。已在开发台式机运行；完整 M2、15 分钟连续玩法、性能基线、Y9000P 笔记本及无开发环境机器的验收尚未完成。

## 启动

1. 解压完整目录，保留 `SymoCraft.exe` 和同级 `assets`，不要只移动 exe。
2. 暂用纯英文路径，例如 `F:/Games/Symocraft-M2-A`。
3. 双击 `SymoCraft.exe`。启动时先生成固定世界，然后进入游戏。
4. 键盘控制前切换为英文输入模式；本机复测曾出现中文输入法组合窗口，影响键盘响应。

程序要求 OpenGL 4.6 Core 和可用的显卡驱动。本包没有附带 Microsoft C++ 运行库安装程序；当前 exe 依赖 `MSVCP140.dll`、`VCRUNTIME140.dll`、`VCRUNTIME140_1.dll` 和 Windows UCRT。若出现缺少运行库的系统提示，请记录提示交回排查，不从不明网站单独下载 DLL。尚未验证干净系统的依赖部署。

## 操作

| 输入 | 作用 |
| --- | --- |
| W / A / S / D | 持续按住移动，松开停止水平移动 |
| 左 Shift | 奔跑 |
| 鼠标 / 滚轮 | 转向 / 调整视野 |
| Space | 接地时跳跃 |
| 左键 / 右键 | 拆除 / 放置方块 |
| Q / E | 切换方块类型，名称输出到控制台，当前没有完整快捷栏 HUD |
| 按住 Caps Lock | 调试无重力、无碰撞模式，不是键盘灯状态切换 |
| 按住 Caps Lock 和左 Ctrl | 下降 |
| Esc | 退出 |

世界固定为 441 个已创建区块，外围不作为完整可玩区域；不会随移动继续生成。玩家落到世界下方时会重新寻找中心附近地面恢复。窗口失焦或最小化时暂停模拟。退出不保存玩家修改。

## 本轮请人工确认

- 持续移动、松键停止、奔跑、跳跃落地和普通墙体碰撞是否正常。
- 鼠标视角、选择框、左右键拆放和 Q/E 切换是否可用。
- Esc 退出后能否再次启动。

反馈请写明现象、操作顺序、位置/截图、构建包名称和是否使用英文输入模式。这份短检查不替代 M2 的完整 14 项用例、15 分钟连续游玩、帧时间采样或笔记本验收。

## 验证入口

从本目录终端运行 `./SymoCraft.exe --check-assets`，只检查必需资源是否存在，不开窗口。

`./SymoCraft.exe --smoke-frames 120` 会打开真实游戏窗口并在渲染 120 帧后退出；它不是性能测试，也不能证明完整玩法通过。

包内 `manifest.json` 记录 exe、资源和说明文件的 SHA256；`build-identity.json` 记录源码基线与构建输入。完整验收报告和技术文档位于源仓库 `docs/milestones/m2-a/README.md` 与 `docs/legacy/architecture/`。

第三方依赖来源及许可材料仍沿用仓库基线，有待后续发布阶段补齐；本包用于项目内部开发验收，不代表已完成公开发布审查。
