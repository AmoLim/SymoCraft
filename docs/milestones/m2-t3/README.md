# M2-T3 性能观测与桌面基线报告

验证日期：2026-10-03。**性能采集实现及桌面正式九轮采样完成，Y9000P 有效基线尚未完成，M2-T3 整体仍待双机数据与用户验收。** 本项没有进行性能优化，不据此宣布 M4 或完整 M2 通过。

后续笔记本反馈：已收到一轮 static-1，因最后约 72 秒失焦而无效；同时修复 Windows PowerShell 5.1 的空退出码及路径兼容性问题。见 [首轮诊断与脚本补丁](laptop-first-run.md)。当前代码 Debug/Release 各 17/17（含本机两种 PowerShell），游戏 exe 未变；下文 15/15 和脚本哈希保留为原桌面基线的历史身份。Y9000P 有效九轮仍未完成。

## 本次交付

- 真实性能帧时间与截断模拟时间分离；事件、模拟、网格、批次装入、上传调用、CPU 渲染提交、GPU 绘制和呈现等待分别记录。

设计理由、数据流、所有权、计时口径、错误处理和测试入口见 [性能观测模块](../../legacy/architecture/performance-observation.md)。复现及笔记本交接见 [双机采样指南](../../project/benchmark/testing/performance-baseline.md) 和 [包内说明](PLAYER-README.zh-CN.md)。

## 正式帧时间

下表每行单独统计 180 秒采样，不包含预热，不删除慢帧，不混合三轮分布。时间单位 ms；FPS 为帧数除以累计真实帧时间，不是逐帧 FPS 的平均。

| --- | ---: | ---: | ---: | ---: | ---: |
| static-1 | 31611 | 175.61 | 6.4195 | 6.9016 | 10.8132 |
| static-2 | 31550 | 175.28 | 6.4649 | 6.9518 | 9.3835 |
| static-3 | 31612 | 175.62 | 6.4386 | 6.9098 | 9.2675 |
| walk-1 | 31754 | 176.41 | 6.4456 | 6.9469 | 10.5888 |
| walk-2 | 31809 | 176.72 | 6.4156 | 6.9133 | 9.4749 |

| edit-1 | 32044 | 178.02 | 6.4423 | 7.1348 | 9.6275 |
| edit-2 | 32508 | 180.60 | 6.2538 | 6.9771 | 8.4933 |
| edit-3 | 31824 | 176.80 | 6.5427 | 7.2284 | 10.0418 |

各轮首个 sample 位于 60..60.1 秒，最后一个位于 239.9..240 秒。静止/移动测量段无编辑、无网格重建；移动三轮均有正反向往返，x 端点仅存在单步轻微越界。编辑每轮测量段 720 次写入、2160 次区块重建，调度最大迟到约 6.75 ms，慢编辑帧保留。

240 秒完整运行中的编辑次数是 959：第一个操作在 0.25 秒，240 秒停止边界不再执行第 960 个操作。三轮最终世界摘要均为 `fnv1a64:d16a5dabbd8619cf`；它不是整周期恢复后的初始摘要。静止/移动最终摘要仍为 `fnv1a64:bddd435ea737fa62`，全部初始地形摘要仍为 `fnv1a64:cd80ebb0446c15c6`。

GPU 样本尾部共缺失 5 帧，各轮缺失 0 或 1 帧，没有为了补齐查询强制等待。分位数仅采用实际返回结果，缺失数见各轮 summary。画面交换间隔不是显示器延迟，GPU 绘制查询也不包含显式上传、清屏或呈现。

## 成本与资源观测

| 指标 | 九轮观测范围与解释 |
| --- | --- |
| 每帧上传 | 约 55.094 MiB，即约 57.77 MB；静止时也持续全批次上传，非显存占用 |
| CPU 批次装入均值 | 2.447..2.506 ms；复制已有有效网格，而非重新生成全部区块网格 |
| 上传调用 CPU 均值 | 2.802..2.932 ms；驱动调用的墙钟时间，不是 GPU 上传时间或纯 PCIe 传输带宽 |
| GPU 绘制 P95 | 0.1125..0.1236 ms；仅当前查询覆盖的 draw 区间 |
| 网格阶段 P99 | 静止/移动 0.0084..0.0104 ms；编辑 1.3282..1.3379 ms |
| 呈现等待 CPU 均值 | 0.0548..0.2732 ms，有轮间波动，不隐去此差异 |
| 进程工作集 | 测量段约 495.57..512.27 MiB；每轮首尾增加约 5.17..5.94 MiB |
| 进程 private bytes | 测量段约 1099.46..1112.14 MiB；每轮首尾变化约 -1.67..+0.29 MiB |
| VBO 请求分配 | 280001200 bytes，约 267.03 MiB；不等同实际全部显存驻留 |
| NVIDIA 设备显存使用 | 传感器完整运行区间 2194..2741 MiB，包含桌面/其他进程，不能归为游戏精确 VRAM |
| GPU 温度 | 传感器完整运行区间 46..50 摄氏度，设备 UUID 与实际 GL renderer 对应 |
| CPU 温度 | 缺失，没有安装或猜测传感器数据 |

采集器本身保存帧数组，内存随记录页触达会增长；工作集不是泄漏的单独证据。当前短区间观测不能证明无泄漏，也不能替代 M5 长时验证。

启动计时中，从 main 入口到首帧交换返回为 **930.11..960.92 ms**，只作为首次可操作画面时间近似，不是输入响应或物理呈现延迟。区块分配 27.75..31.35 ms，地形 77.63..89.33 ms，植被 0.84..1.14 ms，夹具/摘要/元数据 341.00..344.65 ms，首批网格 167.47..179.35 ms，首次上传调用 13.34..15.92 ms。摘要扫描是验证开销，不能算作地形算法成本；首次画面时间也不是未加观测版本的冷启动性能。

**工程判断：** 当前数据支持把“每帧 CPU 批次重装与全量上传”作为后续优化优先候选，而不是先增加线程。该判断来自计时和约 55 MiB/帧的实际上传，不是已完成瓶颈归因或预估优化收益。GPU 查询范围有限，不能由 0.12 ms 宣称全部 GPU 工作几乎免费。仍按 M3 数据边界、M4 同场景对照的顺序推进。
