# M3-T2 人工核查入口

本文件是 T2 的固定人工核查入口，随准备、实施、候选交付和节点验收更新，不因 S3/S5 或包版本变化改名。阶段记录和原始证据保留在原处；从这里查看当前需要你操作、审核报告或批准的事项。

当前节点：**T2 于 2026-10-09 获用户正式批准通过**；FB01 方案2（10 / 12 ms）及 MB01 方案2（704 / 1408 MiB）均已确认。下一节点：T3-R1 已授权准备及自身冻结核对，见 [T3 固定人工入口](../m3-t3/manul-verification.md)；不自动冻结 v1 或授权 R2。批准来源见 [节点批准记录](evidence/t2-approval-20261009.json) 和 [正式计划](../../spec/M3-T2-SDL3迁移.md#节点批准与遗留事项)。下方主表保留全部现有人工填写及结果，不因节点批准把失败/未执行证据改成测试通过；Fix1 继续暂停，首次可操作预算、正式同源采样及其他证据缺口保留为遗留事项，本轮不新增补验操作。

范围依据：[T2 正式计划](../../spec/M3-T2-SDL3迁移.md#验收案例)、[当前硬件与后续性能门槛](../../spec/project-scope.md#m3-本机-rtx-5070-ti-验收与下一玩法阶段性能门槛)。当前功能/兼容只验本机 RTX 5070 Ti，其他 GPU 或第二机器不阻塞 T2。中低端整机性能留在下一玩法功能开发前，不是免验或已通过。

## 随推进更新

开发者在候选变更、阶段交付、取得人工反馈或申请节点批准时同步更新本页的包入口、身份、适用性、结果和证据。编号保持稳定；变化影响及需要重验的具体子项写到对应结果栏，旧结果保留来源链接，不批量清空历史通过或复制一份新的全套待测清单。

新增人工反馈至少含编号、日期、实际包/设备与条件、操作、观察及证据位置。尚无入口或报告时标“待提供”，失败时写最短复现，部分/不可用时写缺项。只有人工操作或审核动作真正完成才勾选，不由自动测试成功或文档编辑代填用户批准。
