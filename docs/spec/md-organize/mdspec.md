# 文档浓缩与迁移试点

> 2026-10-10 OpenSpec 迁移后已退役：本页仅保留原文供复核，元数据、待办及“当前”等文字均属原记录时点，不是现役规格、规则或活动计划。本轮唯一文档迁移计划；前轮新会话已复核，不等同全库收口。现役入口见 [新权威位置](../../openspec/changes/docs-openspec-migration/proposal.md)；来源映射见 [迁移 design](../../openspec/changes/docs-openspec-migration/design.md#来源映射)。旧源未删除，清场须另行确认。

## 当前范围与授权
2026-10-10 用户批准多 Agent 进行规则落地、Renderer/Benchmark/build 试迁移及迁移验证。该授权不包含源码功能修改、提交、发布或最终清场。
现行规则唯一正文是 [DOCUMENTATION_MAP](../../DOCUMENTATION_MAP.md)，旧整理规则与历史执行记录不再作为持续任务。替换前完整工作区正文已保存在本轮临时基线，旧规则历史仍可通过 Git 查询；未提交信息不假定已经入库。

## 活动计划
1. 建立新工作区基线，保护原始 evidence、并行修改与个人目录。
2. 落地规则与阶段/架构/验证入口，修正现行规则冲突。
3. 三个分工按当前代码浓缩 Renderer、Benchmark、工程契约；旧笔记加过渡提示，暂不删除。
4. 复制必要既有冻结材料到 verification，逐文件核对身份，集中关键节点批准。
5. 检查导航、标签、规则、原字节与非文档差异，独立核对契约覆盖。
6. 聊天汇报并提供新会话只读验证 prompt；用户复核后另行授权全库收口。

## 当前状态与未完成
规则、新入口和三域试迁移已落地，契约独立审阅已完成；机械验证逐项核对迁移字节、外层冻结清单、历史包快照、导航与标签。实际结果在聊天内汇报，不追加独立总结；新会话复核尚未进行，不将本轮试点等同全库收口。
本轮没有重跑 C++ 构建、GPU、性能或人工验收。运行态与 Obsidian UI 为未验证，不从链接通过推定通过。
Benchmark install 仍读取旧使用文档和依赖盘点，全库清理前需同步消费者。新会话验收、其他模块迁移和旧文件删除均待后续确认。
复核现场包括旧正文、原 evidence 和临时基线，未确认前不清理。
首次基线遗漏了 evidence 内的部分构建名称目录；副本已补齐，身份依据和历史稀疏包边界见 [VERIFICATION](../../verification/VERIFICATION.md)，不补造开始前的全量基线。
