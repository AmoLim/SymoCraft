# 固定世界与边界回归场景

## 使用方式

M2-T2 提供生成版本 1、测试场景版本 1。当前候选版在 `out/install/m2-t2/SymoCraft.exe`；CLion 构建版使用相同参数。此文定义可复现输入，不是人工玩法通过记录。

以下从仓库根目录运行；在 CLion 中把 exe 后面的参数填写到运行配置的 Program arguments，不是 CMake options。

```powershell
# 普通游戏保留随机开局；指定 seed 则重建固定地形
./out/install/m2-t2/SymoCraft.exe
./out/install/m2-t2/SymoCraft.exe --seed 424242

# 固定测试平台，默认 seed 424242，默认检查点 spawn
./out/install/m2-t2/SymoCraft.exe --scene regression
./out/install/m2-t2/SymoCraft.exe --scene regression --checkpoint four-chunk

# 无窗口报告；完整报告可重定向保存
./out/install/m2-t2/SymoCraft.exe --world-summary --seed 424242 --scene regression --checkpoint four-chunk --test-edits

# 真实驱动运行，120 帧自动退出
./out/install/m2-t2/SymoCraft.exe --scene regression --checkpoint four-chunk --test-edits --smoke-frames 120
```

`--scene terrain` 等同默认普通地形。只有 `regression` 接受 `--checkpoint` 和 `--test-edits`；`--world-summary` 不能与 `--smoke-frames` 同用；`--check-assets` 必须单独使用。不支持运行中传送命令，切换检查点通过退出后带新参数启动。重启会丢弃编辑，没有存档。

随机普通开局会输出实际 `generation.seed`；用相同 seed、版本、配置和构建重启即可重建初始方块，不能恢复已经发生的玩家编辑。不同 `seed_source` 是预期元数据差异。完整确定性边界见 [生成技术说明](../architecture/world-generation.md)。

## 几何与检查点

`regression` 在正常 441 区块世界之上覆盖平台，不减少世界规模。平台 x、z 各为 -24..24，先清空 y=158..174，再在 y=160 放草方块；地板顶面高度 161。这是明确的人工夹具，不伪装成自然地形。边界编辑点使用石头；墙角用圆石，低顶用橡木木板。

坐标是**玩家身体中心**而非眼睛；相机沿用身体上方 0.65 的偏移。yaw/pitch 单位为度，初始 FOV=45。输入后视角和位置仍由正常玩法改变，日志记录的是初始状态。

| checkpoint | 身体中心 x,y,z | yaw / pitch | 目的 |
| --- | --- | --- | --- |
| `spawn` | -20.5,161.9,-6.5 | 0 / -10 | 平直路线起点，朝 +x |
| `positive-x` | 14.5,161.9,2.5 | -63.435 / -25.16 | x=16 交界两侧的 (15,161,0)、(16,161,0) |
| `negative-x` | -17.5,161.9,2.5 | -63.435 / -25.16 | x=-16 交界两侧的 (-17,161,0)、(-16,161,0) |
| `four-chunk` | -2.5,161.9,-2.5 | 45 / -20.4 | x=0,z=0 四区块交点，第一块为 (-1,161,-1) |
| `wall-corner` | 6.5,161.9,6.5 | 45 / 0 | x=8 与 z=8 的 L 形墙，墙高三格 |
| `low-ceiling` | -6.5,161.9,6.5 | 0 / 0 | x=-8..-4,z=4..8,y=163 的顶；地板与顶之间净高 2 |
| `single-block` | 20.5,168,20.5 | -90 / -60 | 从上方落向 (20,164,20) 的单格石头 |

各初始身体 AABB 不与实体重叠已有自动测试，但**未因此证明物理落地、跳跃撞顶或墙角滑动正确**。单块落地的预期稳定中心 y 约为 165.9，必须用真实物理观察验证。平台外会回到自然世界；不要把该夹具的空隙理解为普通地形故障。

## 固定移动路线

路线 `walk-positive-x-v1`：从 `spawn`，保持 yaw=0、pitch=-10，不移动鼠标、不滚轮、不奔跑、不跳跃，沿 +x 普通步行，z=-6.5。依次经过下列身体中心位置：

```text
(-20.5,161.9,-6.5)
(-16.5,161.9,-6.5)
(-0.5,161.9,-6.5)
(15.5,161.9,-6.5)
(20.5,161.9,-6.5)
```

正常步行参数为 4.4 单位/秒，总水平距离 41。该方向不经过编辑石头、墙角或低顶，穿过 x=-16、0、16 的边界。人工执行可持续按 W 约 9.3 秒作为定位参考，但操作系统输入、帧调度和实际物理会带来误差，不以这个估算时间判定坐标正确。

**当前只冻结路线与姿态，不自动注入输入或回放每个物理步。** M2-T3 冻结采样方法时还需明确到达条件、预热、重复路线方式和计时误差；不能把人工持续按键当作位级相同轨迹。测试路线不能代替完整 M2-03 移动验收。

## 固定编辑序列

八个目标按下表顺序逐一执行“拆石头 -> 放指定材料”，共 16 个世界写入。每次正常重启夹具，目标恢复为石头 ID 5；空气 ID 1、橡木木板 ID 8、圆石 ID 11。

| 操作号 | 目标 x,y,z | 变更 |
| --- | --- | --- |
| 1、2 | 15,161,0 | 5 -> 1 -> 8 |
| 3、4 | 16,161,0 | 5 -> 1 -> 11 |
| 5、6 | -17,161,0 | 5 -> 1 -> 8 |
| 7、8 | -16,161,0 | 5 -> 1 -> 11 |
| 9、10 | -1,161,-1 | 5 -> 1 -> 8 |
| 11、12 | -1,161,0 | 5 -> 1 -> 11 |
| 13、14 | 0,161,-1 | 5 -> 1 -> 8 |
| 15、16 | 0,161,0 | 5 -> 1 -> 11 |

`--test-edits` 在创建首批网格之前按上述顺序调用真实 `SetWorldBlock`，核对每一步的原 ID；失败抛异常退出。该入口不经过射线、键鼠、防抖和逐帧网格重建，也不采集编辑延迟；不是方块交互验收或性能编辑负载。

人工复查时不要带 `--test-edits`，按目标组使用对应检查点，调整距离/视角确保选中目标，用 Q/E 选择材料，左键拆、右键从下方地板顶面放回。单次操作间隔至少 0.25 秒，检查选择框、邻块暴露面及碰撞。初始视角面向组内首个目标，其余目标允许移动后观察；跨组重启不等于在一个持续会话执行完整序列。

## 模块与验收边界

[TestScene](../../src/world/test_scene.cpp) 提供 `Install()`、`Checkpoints()`、`Checkpoint(name)`、`Edits()`、`ApplyEdits()` 和 `Describe()`。返回的 span 引用模块静态只读数组，不需调用方释放。`Install` 要求至少半径 3 的可玩覆盖，写入前检查覆盖范围；`ApplyEdits` 要求初始石头状态，重复调用会拒绝，且不承诺中途失败时回滚已完成操作。

生成/编辑通过区块原有写入入口传播脏标记，未新增另一份测试专用世界实现。摘要分别保存自然世界、覆盖后、编辑后状态。报告还输出完整几何参数、检查点、路线和编辑操作；只保存 seed 不足以描述测试输入。

本项覆盖“可定位、可重建、可比较”。后续 [14 项玩法验收](gameplay-smoke.md) 仍要分别记录人工结果、截图/录像、坐标及异常；固定夹具不能自动使 M2-05、M2-09、15 分钟游玩或笔记本通过。真实性能帧数据属于 M2-T3。
