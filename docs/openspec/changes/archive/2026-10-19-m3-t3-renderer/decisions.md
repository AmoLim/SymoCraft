## 2026-10-15 Vulkan已选预算与正式配对口径

用户先要求按D3D12采样方法对Vulkan进行性能验收，随后明确同意聊天所列完整口径。本次独立选择Vulkan预算并授权执行，不是自动继承D3D12批准或由实测倒定阈值。

同版本Release的GL与Vulkan分别执行static/walk/edit各三轮、每轮独立进程，先GL九轮再Vulkan九轮，每轮10秒预热＋50秒正式采样；seed424242、441区块、regression v1/workload v2、实际1920×1080/4x、VSync-off、allow-unfocused。每组按相同场景/轮次配对：Vulkan P95≤10ms、P99≤12ms，且各自≤对应GL的110%；工作集和私有提交分别取10≤elapsed_s<60内约每秒观测最大值，各自≤对应GL同口径最大值的110%。不相加/混池/平均/挑最好/删除慢帧，不补缺失为0；内存不含显存、启动、截图、导出，也不叠加T2绝对上限。其他指标只观测，不新增启动时间等硬预算。

本轮重新采集同版本GL基线，不借2026-10-13旧GL或旧D3D12超限轮替代；现代安装004与同批独立GL包分别绑定源码/构建/资产身份，不在GL-off现代包里假称运行GL。Vulkan开启validation，GL按实际配置记录；实际后端/5070Ti/驱动、呈现、图像尺寸、世界摘要、有效编辑及生成身份由既有原生消费者/报告探针逐轮复核。保留全部焦点与长帧，失焦不使协议无效；沿用原采集器对配对焦点条件可比性的单独判断，不将mixed/不匹配的数值通过写成已验证同条件预算通过。

无效/超限保留并报告，不自动复测、优化或放宽。18分钟短窗口不证明原60＋180长窗口、罕见卡顿、瞬时峰值或长期内存增长；结果有效、预算通过、R4/T3批准分别记录。本次只允许必要采集脚本/测试兼容扩展，不改生产玩法/渲染、默认D3D12或删除GL；D3D12 edit第3轮P99缺陷继续暂缓，Fix1/T4/Git/sync/archive及新人工验收不由此启动。

## 2026-10-14 Vulkan有限呈现退休能力

用户明确授权继续R4生产实现，并批准将 `VK_KHR_swapchain_maintenance1` 或 `VK_EXT_swapchain_maintenance1` 的 `swapchainMaintenance1` feature / presentation fence列为必需能力。这替代原Vulkan1.2加surface/swapchain的能力下限；不支持时具名Unsupported，不降级、不转其他设备/API。公开v1签名、线程及有限关闭语义不变，D3D12默认与GL过渡保持。

原因是[核心呈现寿命说明](https://docs.vulkan.org/guide/latest/swapchain_semaphore_reuse.html)：submit fence只证明提交工作完成，不能证明呈现端释放wait semaphore/交换链；WaitIdle无有限超时且不是未扩展呈现完成证明。生产使用实际presentation fence覆盖复用、尺寸重建和关闭；有限等待失败停止续交并终止保留完整owner/loader，不冒称正常回收。代价是拒绝缺该扩展/feature的Vulkan1.2设备；本机前置实验支持不等于生产接管通过。R4/A01–A19及Vulkan预算独立验证，D3D12性能缺陷继续暂缓。

本页维护本 change 的已选设计及其限定身份；批准/冻结只从 [VERIFICATION](../../../../verification/VERIFICATION.md) 判读，不据迁移重新选型或扩权。

### D3D12 已选预算口径

同日用户确认帧时间方案 4 及内存 10% 相对回归，并明确同意以下内存口径同步规格。仅用于本机 D3D12 与同版本、同机、同配置、同工作负载 GL 的正式对照；static / walk / edit 各三轮，逐场景、逐对应轮次同时判定全部条件，不混池、平均、挑最好或删除慢帧：

| 指标 | 每轮正式采样段的条件 |
| --- | --- |
| P95 帧时间 | <= 10 ms，且 <= 对应 GL 轮次 P95 的 110% |
| P99 帧时间 | <= 12 ms，且 <= 对应 GL 轮次 P99 的 110% |
| 工作集 working set | 约每秒观测值的最大值 <= 对应 GL 轮次同口径最大值的 110% |
| 私有提交 private bytes | 约每秒观测值的最大值 <= 对应 GL 轮次同口径最大值的 110% |

两项内存各自判断，不相加、不取平均或分位数；这是正式采样段内的观测最大值，不是瞬时或整个进程生命周期峰值，不包含显存、启动阶段，也不叠加 T2 的绝对内存上限。帧时间不以平均 FPS 代替 P95/P99，CPU/GPU/present 分位数不相加。

本轮只确定帧时间与进程内存硬预算；启动/首次可操作时间及其他性能指标继续如实观测，缺失具名，不新增其数值通过门槛。不可恢复故障、协议无效、泄漏或隐性降低画面/工作负载仍不能因预算满足而豁免。T2 的既有预算、前台适用条件、成绩及下一玩法前的中低端整机门槛保持原义，不自动移用；Vulkan 的预算须另确认，不继承本次选择。

正式观测协议仍以 [项目范围](../../../../scope/project-scope.md#性能目标与测量约束) 为依据；同版本 GL 配对正式基线尚未建立，不把 T2 的短协议或复测授权带入。预算确认时仅同步规格、不启动正式采集；快速协议检查、旧数据消费者复核、构建通过或用户报告的 15 分钟无异常均不替代正式预算对照。后续本轮执行范围按下节用户追加决定，不将未执行的九轮重新列为本轮待启动工作。
