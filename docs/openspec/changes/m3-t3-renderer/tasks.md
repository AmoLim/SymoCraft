# T3 唯一活动计划

这里承接原 R1–R4；勾选仅记录注明身份的既有交付或后续真实完成，不代表新的代码授权或节点批准。
验收行为见 [delta](specs/renderer/spec.md)，批准/运行/归档边界见 [VERIFICATION](../../../verification/VERIFICATION.md)。本轮只迁移文档，未执行下列动态或人工检查。

## 1. R1 契约与关键实验（既有节点）

- [x] R1：核对T0/T1/T2交接与公开v1/target设计，完成D3D12本机Debug/Release R1-E01–E03及独立CPU交接；2026-10-09用户冻结设计并批准R2。此项是历史节点，不重启实验，也不冻结完整私有RHI。

T3-M01–M07保留为2026-10-09用户**报告/设计审阅**身份：M01包/设备，M02纹理/颜色，M03资源，M04窗口，M05失败/有限等待，M06v1/CPU所有权，M07平台/target/剩余风险。不是当日新运行，原勾选与命令只在冻结历史保存，不形成第二活动批准表。

## 2. R2 门面与 D3D12 候选

- [x] R2-顺序1：公开三头、CPU PImpl/registry/状态/错误与真实CPU target已实现，历史CPU证据不扩为GPU接管。
- [x] R2-顺序2：真实私有D3D12设备/资源/呈现/shader/同步/查询/截图已实现，有限GPU结果与批准alpha-depth修正绑定原顺序2身份。
- [x] R2-顺序3：GameRenderer与WorldRenderCache接入同一游戏循环，持久网格与真实atlas/相机转接已交付。
- [x] R2-顺序4：D/R `d3d12-game-*-002`安装候选及有限完整世界/窗口/隔离故障复核已交付；默认仍GL，不能将候选交付当R2/R3整体验收。
- [ ] R2-缺口：具名处理实际设备/提交/真正在途timeout/分配故障、现代独占及全关闭、关闭测试/工具补充配置、旧Benchmark现代协议、正式视觉参考/容差与同条件预算；保留Win32 1175等遗留状态，未运行项目不得标通过（A01–A18）。

## 3. R3 D3D12 接管与默认切换

- [ ] A01–A05：在实际生产target完成公开消费者/越界拒绝、CPU-only/benchmark-only、D/R单后端矩阵、依赖/增量、实际硬件/不支持路径；未选Vulkanloader缺失测试待R4组合包存在后执行。
- [ ] A06–A12：完成基础立方体/真实图集/选择框、固定完整世界与相机、编辑/空网格/输入寿命、在途更新删除容量、连续resize/最小化至少10秒恢复、实际VSync/MSAA；不由局部夹具整项关闭。
- [ ] A13–A17：完成隔离资源/分配故障、真实与注入分列的DeviceLost/提交/timeout、正常/构造失败/重复关闭、诊断工具、截图与原frame ID异步样本。
- [ ] A18：完成现代与旧GL协议兼容消费者、具名中立采样，从无关CWD/安装目录运行与实际部署依赖验证，不把本机Release短测当无SDK新机器验证。
- [ ] A19：本机RTX5070Ti逐项适用14项玩法及至少15分钟连续实际操作并正常退出；不是M5 60分钟或中低端性能通过。
- [ ] T3-M08：用户核查D/R002源码/构建/包hash与实际后端/adapter/驱动/样本/present/validation；Debug不对外再分发。
- [ ] T3-M09：用户核查固定441区块、图集/UV/层/相机/深度/剔除/选择框，现代alpha-depth差异不能解释全部画面差异。
- [ ] T3-M10：用户审阅静止/移动零几何重传、编辑及边界，结合CPU/原生证据核查空网格/句柄/回收；画面不证明fence安全。
- [ ] T3-M11：用户操作连续最小化至少10秒、恢复比例/输入、Esc和关闭按钮退出后重启；自动WM_CLOSE不替代Esc。
- [ ] T3-M12：用户审阅隔离缺/坏DXIL、PNG/YAML、无效后端分类与有限退出，不修改原包；不关闭真实A14。
- [ ] T3-M13：用户审阅PNG、frame ID/缺失原因、中立CSV/YAML、旧GL与无关CWD/空格路径/CRT/notices/部署限制。
- [ ] T3-M14：用户审阅公共头/CPU-only/target/增量/D/R全量结果，区分过渡包与尚未测配置。
- [ ] T3-M15：用户完成当前候选14项玩法及至少15分钟，记身份/时段/问题/退出；历史T2/M2成绩不继承。
- [ ] R3-批准：缺口、适用A01–A19及人工要求成立后申请D3D12接管；用户批准后才切默认，明确过渡GL去向。人工检查不自动等于节点批准。

T3-M08–M15须记录日期、执行者、版本、实际身份、操作与证据；本计划未代填人工结果。旧[人工页](../../../milestones/m3-t3/manual-verification.md)只保留原反馈及点时命令/候选入口，不再维护第二活动计划。

## 4. R4 Vulkan 与双现代整体验收

- [ ] R4-实验：本机独立核实Vulkan1.2/surface/swapchain能力与工具链，重跑R1-E01–E03，核对输入布局/颜色/寿命/呈现，不继承D3D12结果。
- [ ] R4-实现：复用v1落实真实私有Vulkan资源/命令/同步/呈现/loader寿命和DXIL/SPIR-V同源shader；若改变公开契约/能力先受控确认，不建空target冒充。
- [ ] R4-验收：逐后端完成全部适用A01–A19与实际候选人工核查，补现代两种单后端/双后端D/R、惰性loader、安装资产及旧GL隔离证据。
- [ ] R4-批准：两现代分别完整接管、整合及v1复用成立后申请T3整体验收；下一玩法前中低端整机性能门槛仍独立保留。
