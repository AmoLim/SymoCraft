### 2. S02 Registry 身份、对象与失败契约

依赖 S01 的适配与生产入口成立，不要求第三层集成已通过。

- [ ] 2.1 接入固定本地 EnTT 与受控配置 target，落实稳定 Registry owner、项目 typed/detail 边界及 RAII；关闭空类型优化的实际路径与所有消费者一致，禁止原生逃生口。（A01、A09、A21）
- [ ] 2.2 实现不复用 owner/incarnation、非拥有 EntityId 的空值/相等/哈希、创建/严格销毁/末代拒绝与 Clear 先准备后清理；析构不申请新身份，不恢复旧 ID。（A02-A06、A20）
- [ ] 2.3 实现每实例显式注册、自有首次名称、重复幂等和独立类型碰撞拒绝，取消 256 限制；严格新增/默认获取或新增/布尔移除按对象生命周期运行，落实模板修饰和 const 规则。（A07-A11）
- [ ] 2.4 实现有效性/注册状态、Get/Has/TryGet、单实体组件数、统一分层检查、可恢复失败与 Failed 最小自有摘要；不新增业务校验钩子或一般统计接口。（A12、A16、A18、A19）
- [ ] 2.5 对上述路径补真实生产库的正常/拒绝/构造抛错与代表性分配失败用例，包含非尾/少量/高索引移除、空对象/资源计数及 Clear 失败；不通过越期借用验证失效，不把专用 ABI 成绩当普通 Debug 结果。（A01-A13、A18-A20、A23）

### 3. S03 同步查询、有序键与借用边界

依赖 S02 的注册、身份、对象读取及公共检查。

- [ ] 3.1 实现必需/排除 typed 同步遍历、无必需组件路径、固定 ID 加模板顺序引用协议、void/显式枚举退出和 Completed/Stopped；const、非法模板及回调形式有编译期正负例。（A10、A14、A15）
- [ ] 3.2 实现覆盖准备与回调全程的 RAII 查询深度保护、同步嵌套及独立退出；全部结构入口含预计无变化路径均拒绝，异常只恢复相应层，不自动提交收集项。（A13、A15、A16）
- [ ] 3.3 实现自有完整键收集、std::less<> 排序、业务 visitor 前平局检查及只读键生成；核对准备失败零业务回调，不使用内部实体编号补序或重排底层池。（A17）
- [ ] 3.4 补筛选集合、无组件实体、嵌套 Stop/抛错/捕获、多错优先级、查询中无变化结构入口及有序键/暂存失败测试；默认无序不固定 native 顺序，借用限制写在真实公开入口。（A13-A17、A23）
